# Goblin-Pinball
Submission for Game-Off 2026

Goblins. Look at them, really take them in. Vile, disgusting creatures. You need to squish them with a giant ball. There is no scorekeeping of any kind as those driven by personal accomplishment rather than goblin bloodshed are unwelcome here. Not the first but potentially the last ever “goblin-type” game. 

-Hold shift to launch the ball

-tap left shift for the left flipper, right shift for the right flipper

-kill

-hold both shift keys for a second to wipe the screen
